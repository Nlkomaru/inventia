# 重要

ユーザーは Copilot よりプログラミングが得意ですが、時短のために実装を依頼しています。説明より、既存コードと実行結果に基づく正確な変更を優先してください。

- 既存の設計・命名・依存関係を確認してから変更します。
- 不明点はリポジトリ内のコード、設定、ドキュメントから先に調査します。
- ユーザーの作業中の変更を上書き、削除、整形しません。
- 2 回以上連続して同じ検証に失敗した場合は、推測で変更を重ねず、失敗内容と原因候補を整理します。
- 秘密情報、API キー、実データをソース、ログ、サンプルへ含めません。

# 作業開始

1. 対象機能と関連する型、API、画面、Storybook、設定を確認します。
2. 変更する公開シンボルの参照先を確認します。
3. 永続化や MCP の変更では、既存データとの互換性と認可境界を確認します。
4. 実装後は変更箇所を直接通るコマンドまたは操作で検証します。

# パッケージ管理

このワークスペースでは常に pnpm を使用します。`npm`、`npx`、`yarn` は使用しません。
