# ドキュメント

- 公開 API または MCP tool を変更した場合は、OpenAPI/MCP のスキーマ、title、description、成功例、利用者が対処できるエラーを同時に更新します。
- セットアップ、環境変数、binding、マイグレーション、検証コマンドが変わる場合だけ `README.md` を更新します。
- 秘密情報や実在する在庫データを例に使いません。
- ISBN、ASIN、URL の例は架空または公開された例を使い、正規化後の値も示します。
- 実装していない機能を将来形で利用可能と記載しません。

# Storybook

- `app/src/components/` に再利用可能な UI コンポーネントを追加・変更した場合は、`storybook/src/` の対応する `*.stories.tsx` を更新します。
- 通常、空、読み込み中、エラー、無効、キーボードフォーカスなど、利用者が遭遇する状態を表現します。
- 在庫数量、識別子、長いタイトル、外部 URL など実データに近い境界値を含めます。
